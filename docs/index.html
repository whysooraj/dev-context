Local-First Developer Context

Resume at speed.
Hand off with zero cold start.

One local CLI and zero-dependency stdio MCP server for Antigravity, Claude Code, Cursor, and Codex. Persist goals, uncommitted diffs, and focus queues on disk so every new session begins on the exact next action.
